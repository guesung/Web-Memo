카테고리 대기가 화면 전체를 막지 않도록

기본 메뉴와 검색창은 먼저 표시하고, 카테고리 영역만 자리표시자로 기다립니다. 아래 화면은 합성 데이터로 만든 구조 시안입니다. 현재 서비스 스크린샷이나 성능 개선 결과가 아닙니다.

변경 전 카테고리 완료 후 진행

변경 후 화면 준비와 조회를 겹쳐 진행

바뀌는 상태
카테고리를 기다리는 동안 메뉴·검색·목록 스켈레톤을 표시합니다. 카테고리 추가·선택은 데이터 준비 후 노출합니다. 카드가 카테고리 데이터를 기다리는 기존 동작은 유지합니다.

검증 기준
카테고리가 느려도 초기 화면과 메모 요청이 먼저 시작되는지, 서버·브라우저의 중복 카테고리 조회가 없는지 확인합니다. 정상 완료 후 배치·메뉴·편집 동작은 현재 화면과 같아야 합니다.
